

## Роль полиномиальных функторов для M-типов

Для W-типов полиномиальный функтор задаёт **форму ветвления**, а индуктивный характер (начальная алгебра) обеспечивает фондированность. Для M-типов функтор играет иную роль.

### M-типы = терминальные коалгебры

M-тип для полиномиального функтора `P(X) = Σ(a:A). B(a) → X` — это **терминальная коалгебра**:

```
M ≅ Σ(a:A). B(a) → M
```

Здесь функтор задаёт **шаблон наблюдения**, а не построения.

### В чём смысл

**1. Коиндуктивная генерация**

Вместо "построить дерево снизу вверх" (индукция) мы говорим: "что можно наблюдать сверху вниз" (коиндукция). Функтор определяет, какие наблюдения допустимы на каждом шаге.

**2. Бисимуляция вместо индукции**

Доказательство равенства элементов M-типа — это не индукция по конструкторам, а нахождение **бисимуляции**: бинарного отношения, замкнутого относительно шагов функтора. Два элемента равны, если они бисимулярны.

**3. Непрерывное раскрытие (unfolding)**

Каждый элемент M-типа можно бесконечно раскрывать:

```
x : M  →  (a, f) : Σ(a:A). B(a) → M
                                    ↑
                              f(b) снова элемент M
```

Функтор гарантирует, что это раскрытие всегда возможно и согласовано.

**4. Контроль над "размерностью" бесконечности**

Полиномиальная структура задаёт **локальную конечность** ветвления (каждый узел имеет конечное число дочерних позиций `B(a)`), даже если дерево бесконечно. Это отличает M-типы от произвольных коалгебр:

- `Stream A = νX. 1 × A × X` — бесконечные последовательности
- `M(A, B) = νX. Σ(a:A). (B a → X)` — более общий случай с ветвлением

Функтор определяет **арность** ветвления в каждом узле.

### Сравнение

| | W-типы (алгебры) | M-типы (коалгебры) |
|---|---|---|
| **Функтор задаёт** | конструкторы | наблюдения |
| **Фиксированная точка** | начальная | терминальная |
| **Доказательство** | индукция | бисимуляция |
| **Элементы** | строим ↓ | раскрываем ↑ |
| **Фондированность** | гарантирована | не требуется |
| **Смысл функтора** | "как строить" | "что наблюдать" |

### Практический смысл

Полиномиальный функтор для M-типов — это **спецификация процесса**:

- `A` — возможные метки/состояния узлов
- `B(a)` — возможные действия/наблюдения в состоянии `a`
- `M` — все возможные бесконечные вычисления/поведения, согласованные с этой спецификацией

Так что функтор для M-типов — это не "чертеж дерева", а **автомат или процесс**, чьи возможные executions и есть элементы M-типа.
